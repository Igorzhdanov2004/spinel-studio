# 💎 Spinel Studio — Генератор неупорядоченных суперъячеек шпинелей

Интуитивное веб-приложение для геологов, кристаллохимиков и материаловедов для построения и статистического анализа катионного разупорядочения в суперъячейках шпинелей ($AB_2X_4$).

## Ключевые возможности
* **Строго раздельное перемешивание подрешёток:** тетраэдры ($A$, $CN=4$) и октаэдры ($B$, $CN=6$) оптимизируются независимо методом Монте-Карло по критерию $\chi^2$ с учётом периодических граничных условий (PBC).
* **Понятные режимы работы:**
  1. **Реальные многокомпонентные шпинели** (`Co`, `Ni`, `Mn`, `Fe`, `Cr`, `Mg`, `Al`, `Zn`, `Ti` и любые элементы таблицы Менделеева с расчётом рентгеновской плотности $\rho$).
  2. **Бинарные твёрдые растворы типа A–B** (готовая серия `32:224`, `64:192`, `85:171`, `128:128` + интерактивный конструктор любой процентной доли от 0 до 100%).
  3. **Модельные многокомпонентные системы (`ABCDE`)** с условными метками катионов.
  4. **Произвольные составы с нуля** с пересчётом процентов в целые атомы, помощником электронейтральности ($Q = 0$) и сохранением/загрузкой рецептов в `.json`.
* **Гибкий выбор кристаллического каркаса:** встроенный генератор идеальной шпинели $Fd\bar{3}m$ любой кратности ($2\times2\times4$, $2\times2\times2$, $3\times3\times3$ и др.) или загрузка собственных файлов координат (`.docx`, `.txt`, `.gin`, `.out`, `.cif`).
* **Полный пакет выходных файлов в один клик (`.zip`):**
  * `*.gin` — входной файл для расчётов в **GULP** (`single`, `opti conp`, `opti conv`);
  * `*.cif` — 3D-структура для визуализации в **VESTA**;
  * `*_table.docx` и `*_table.txt` — отчёт **Word** со сводкой и таблицей координат/зарядов;
  * `*_histograms.png` — научные чёрно-белые гистограммы (`300 dpi`);
  * `*_statistics.csv`, `*_pair_contacts.csv`, `*_stoichiometry.csv` — таблицы распределения однородных контактов и параметров Уоррена–Каули $\alpha_{ij}$ для **Origin / Excel**;
  * `*_config.json` — сохраняемый рецепт состава.

## Быстрый запуск на своём компьютере

### Вариант А. Ubuntu / WSL / Linux / macOS
```bash
pip install -r requirements.txt
python3 -m streamlit run app.py
```
*(Либо просто запустите `./run_linux_mac.sh`).*

### Вариант Б. Windows (без командной строки)
Распакуйте папку проекта и дважды кликните по файлу **`run_windows.bat`** — скрипт сам установит нужные пакеты в локальное окружение `.venv` и откроет приложение в браузере.

## Публикация в интернете (чтобы геологи открывали просто по ссылке)
1. Загрузите файлы этого репозитория (`app.py`, `engine.py`, `presets.py`, `verify_core.py`, `requirements.txt`, `.streamlit/config.toml`) в свой репозиторий на **GitHub**.
2. Зайдите на бесплатный сервис **[Streamlit Community Cloud](https://share.streamlit.io/)** под своим аккаунтом GitHub.
3. Нажмите **Create app**, выберите репозиторий, укажите главный файл **`app.py`** и нажмите **Deploy**.
4. Через 1–2 минуты вы получите постоянную веб-ссылку, которую можно отправлять коллегам — им ничего не придётся устанавливать на компьютер.
